# 简介 {#introduction}

UNO Overlays 让你在 Linux 上通过 OpenDeck 用按键和旋钮控制 [UNO](https://overlays.uno)（Singular.live）的叠加层：显示与隐藏、服务器槽位、记分牌、时钟、数据源、投票、目标、宏、OBS Studio 和诊断。

它为 Rise Mode Vision 01（15 个按键）和 Vision Sound 01（6 个按键、3 个旋钮和 3 个无屏按钮）设计，也适用于 OpenDeck 支持的所有设备。

- 每个按键都显示其状态：未播出时图标为**白色**，播出中为**亮红色**。状态实时来自 UNO。
- 来自任何设备、按键、旋钮或检查器的每个 UNO 操作，都经过**一个全局队列**，逐个按顺序执行。
- 触发器、互斥组和控制应用列表都是**全局**的：无论屏幕上是哪个配置文件或设备，它们都能工作。

# 安装 {#installation}

## 要求

- Linux 版 OpenDeck 2.6.0 或更新版本。
- Python 3.10 或更新版本，并带有 HTTPS 证书（Debian/Ubuntu：`sudo apt install python3 ca-certificates`）。
- 能访问互联网以连接 UNO。
- OBS Studio 28 或更新版本，仅用于 OBS 动作和触发器。
- 其他都不需要：唯一的依赖（`websockets`）已包含在软件包中。

## 安装或更新

1. 从发布页面下载 `opendeck-uno-overlays-<版本>-linux.plugin.zip`。
2. 在 OpenDeck 中打开 **Plugins → Install from file** 并选择该文件。
3. 安装会替换插件之前的文件夹。按键、旋钮和设置都会保留：插件及其动作的标识符没有改变。
4. 如果某个按键没有更新，请重启 OpenDeck。

![OpenDeck：Plugins → Install from file](botao_instalar_plugins.jpg)

## 从 1.0 版更新

- 叠加层按键的触发器会在每个按键第一次出现时自动移到全局列表。从未出现的按键（其他配置文件、未连接的设备）会保留旧触发器，直到它出现一次：更新后请把该配置文件打开一次。
- 选项“播出中的编辑（可选）– 隐藏、修改、再显示”已不存在：播出中的编辑总是在设置页面设定的停顿之后直接写入。

# 入门 {#first-steps}

1. 在 UNO 中打开叠加层的控制应用，**? → API Description**，复制令牌：地址中 `/controlapps/` 与 `/api` 之间的部分。请使用控制令牌，而不是 OBS 中使用的输出 URL。
2. 在 OpenDeck 中把一个 **UNO Overlays** 动作拖到按键上，将令牌粘贴到 **API 令牌**，然后点击 **连接 / 重新加载**。
3. 选择叠加层（列表支持搜索和 ★ 收藏）以及按键的功能。表单中的编辑会直接发送到 UNO；请等待 **已保存到 UNO。**
4. 每个字段旁都有一个 **?**：把指针移到上面，或用 Tab 键到达它，即可阅读该字段的作用。按 Esc 关闭说明。

## 语言

插件支持葡萄牙语（巴西）、英语、西班牙语、意大利语、德语、日语、简体中文、韩语和法语。选择 **自动（OpenDeck 的语言）** 时，跟随 OpenDeck 设置中选择的语言；在设置页面选择的语言优先。OpenDeck 不提供意大利语，因此意大利语只能在设置页面中选择。OpenDeck 的语言改变后，请重新打开检查器或设置页面，让插件读取新语言。

## 触发器

触发器在事件发生时执行一个功能，就像 vMix 的触发器：在最长 30 000 ms 的延迟后显示或隐藏一个叠加层。事件：OBS 场景进入或离开节目、推流开始或停止、录制开始或停止、UNO 叠加层开始或结束播出（即 1.0 版中的“当此叠加层开始/结束播出时”联动）。使用 **添加触发器** 按需添加；每个触发器都可以关闭而无需删除。

每个触发器都会写入插件日志：收到的事件、判断结果（已触发或已忽略及原因）以及 UNO 中的结果，不含令牌。

## 互斥组

同一组的叠加层不会同时播出：显示其中一个会隐藏其他的，包括按键不在屏幕上的那些。叠加层按键按名称选择所属组；时间和成员在设置页面中设置。

# 工作原理 {#how-it-works}

- **全局队列。** 所有设备的所有按键、旋钮和检查器都进入同一个队列：一次一个 UNO 操作，按顺序执行。对同一字段的多次转动会合并为一次写入。
- **限制。** 达到 UNO 公布的限制时，队列会等待下一个时间窗口。uno 免费方案每天最多 10 000 次 App API 调用；状态按键会计数。
- **写入。** 只有服务器确认后写入才算完成；超时后不会自动重复。
- **播出中的编辑。** 叠加层播出时，编辑会在一段无变化的停顿（默认 1000 ms）后才发送，观众永远不会看到打了一半的文字。关闭检查器、切换到另一个字段、按下按键或紧急停止都会立即发送。
- **不在屏幕上的按键。** 自动关闭（Auto Close）计时器和已经按下的操作在切换配置文件后会继续；只有按键设置真正改变、紧急停止或再次按下才会取消它们。

# 限制 {#limitations}

- **面板与旋钮。** 面板按键和它的旋钮只有在两者都在屏幕上时才能工作：旋钮保存着正在选择的内容，而 OpenDeck 只向插件报告所选配置文件中的旋钮。
- **恢复。** “恢复”要重新显示的叠加层集合保存在内存中：插件重启后会丢失。
- **触发器延迟。** 已经在计时的触发器延迟在编辑触发器后仍会继续；紧急停止会取消它。
- **已删除的按键。** OpenDeck 在删除按键和切换其配置文件时发送相同的事件，因此正在计时的自动关闭会正常结束（最多 120 秒）。
- **迁移。** 1.0 版的触发器只有在其按键至少出现一次时才会移到全局列表。
- **问答。** 揭晓答案是通用动作：请选择你的叠加层用来揭晓答案的字段和值。

# 使用场景 {#use-cases}

## 记分牌

每支队伍一个数值字段按键（按键显示 +1、+2、+3…），每个比分一个数值显示按键，撤销、锁定、队伍换边时的交换场地、用于节次的循环，以及结束时按住 2 秒的重置。

## 问答

一个开启了轮播的槽位转盘旋钮：每转一格就把下一道题播出；按下可显示或隐藏叠加层。一个揭晓答案按键揭晓答案，并把正确选项复制到高亮字段；下一道题出现时会自动再次隐藏。

## 时钟

文本字段中的时钟按键：倒计时、正计时、当前时间或到结束时间，并带有收尾颜色。在旋钮上，转动可调整时间，面板按键会显示它。

## 滚动字幕与列表

数据源可使用手动输入的列表、.txt 或 .csv 文件，映射到叠加层的字段，支持 Auto Next 和循环。

## OBS Studio

OBS 场景按键切换节目场景，并可显示一个叠加层。触发器可以在“Webcam”场景进入节目时显示摄像机字幕条，在离开时隐藏它。OBS 刷新浏览器可重新加载多个浏览器来源，或某个场景中的所有浏览器来源。

# 故障排除 {#troubleshooting}

- **“请输入控制 API 令牌，而不是输出 URL。”** 只粘贴令牌（字母、数字、`_` 和 `-`）。
- **“UNO HTTP 4xx”。** 令牌错误或已被撤销：请在 **API Description** 中重新复制。
- **“UNO HTTP 429”。** 请求过多：请稍等；避免使用以同一令牌查询 UNO 的工具。
- **“OBS 未连接…”。** 请在设置页面中设置，并确认 OBS 已打开。
- **齿轮打不开任何东西。** 没有设置默认浏览器：`xdg-settings get default-web-browser` 可显示系统使用的浏览器。
- **按键只显示警告。** 控制台已锁定（控制台锁定为红色），或按键不在允许的 OBS 场景中。
- **触发器没有执行。** 查看插件日志：每个触发器都会写明是已触发还是已忽略以及原因。日志：`~/.local/share/opendeck/logs/plugins/dev.br.consciencia.opendeck.uno-overlays.sdPlugin.log`

# 隐私与安全 {#privacy}

叠加层的名称和文本属于个人数据，会发送到 UNO。插件不会向作者发送任何内容，也不会在日志中写入令牌。令牌保存在本机 OpenDeck 的设置中；设置页面绝不会回显令牌或 OBS 密码。保存的场景和日志可按要求删除（删除已保存的场景、清除日志）。如需行使巴西 LGPD 规定的权利，请在项目中提交 issue。详情见插件的 PRIVACY.md 和 SECURITY.md。
