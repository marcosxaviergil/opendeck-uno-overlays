# 소개 {#introduction}

UNO Overlays는 Linux의 OpenDeck에서 키와 노브로 [UNO](https://overlays.uno)(Singular.live)의 오버레이를 제어합니다. 표시와 숨기기, 서버 슬롯, 스코어보드, 시계, 데이터 소스, 투표, 목표, 매크로, OBS Studio, 진단을 지원합니다.

Rise Mode Vision 01(키 15개)과 Vision Sound 01(키 6개, 노브 3개, 화면 없는 버튼 3개)을 위해 설계되었으며, OpenDeck이 지원하는 모든 장치에서 동작합니다.

- 모든 키가 상태를 보여 줍니다. 아이콘은 방송 중이 아닐 때 **흰색**, 방송 중일 때 **밝은 빨간색**입니다. 상태는 UNO에서 실시간으로 옵니다.
- 모든 장치, 키, 노브, 인스펙터에서 오는 UNO 작업은 **하나의 전역 대기열**을 거쳐 한 번에 하나씩 순서대로 실행됩니다.
- 트리거, 배타 그룹, 컨트롤 앱 목록은 **전역**입니다. 화면에 어떤 프로필이나 장치가 있어도 동작합니다.

# 설치 {#installation}

## 요구 사항

- Linux용 OpenDeck 2.6.0 이상.
- HTTPS 인증서가 있는 Python 3.10 이상(Debian/Ubuntu: `sudo apt install python3 ca-certificates`).
- UNO와 통신하기 위한 인터넷 연결.
- OBS Studio 28 이상(OBS 동작과 트리거에만 필요).
- 그 밖에는 필요 없습니다. 유일한 의존성(`websockets`)이 패키지에 포함되어 있습니다.

## 설치 또는 업데이트

1. 릴리스에서 `opendeck-uno-overlays-<버전>-linux.plugin.zip`을 내려받습니다.
2. OpenDeck에서 **Plugins → Install from file**을 열고 파일을 선택합니다.
3. 설치하면 이전 플러그인 폴더가 교체됩니다. 키, 노브, 설정은 그대로 남습니다. 플러그인과 동작의 식별자는 바뀌지 않았습니다.
4. 키가 업데이트되지 않으면 OpenDeck을 다시 시작하세요.

![OpenDeck: Plugins → Install from file](botao_instalar_plugins.jpg)

## 버전 1.0에서 업데이트

- 오버레이 키의 트리거는 각 키가 처음 나타날 때 자동으로 전역 목록으로 옮겨집니다. 한 번도 나타나지 않는 키(다른 프로필, 연결되지 않은 장치)는 한 번 나타날 때까지 이전 트리거를 유지합니다. 업데이트 후 해당 프로필을 한 번 열어 주세요.
- 옵션 "방송 중 편집 (선택) – 숨기고, 바꾸고, 다시 표시"는 없어졌습니다. 방송 중 편집은 설정 페이지에서 정한 대기 시간이 지난 뒤 항상 바로 기록됩니다.

# 시작하기 {#first-steps}

1. UNO에서 오버레이의 컨트롤 앱을 열고 **? → API Description**에서 토큰을 복사합니다. 주소에서 `/controlapps/`와 `/api` 사이의 부분입니다. OBS에서 쓰는 출력 URL이 아니라 제어용 토큰을 사용하세요.
2. OpenDeck에서 **UNO Overlays** 동작을 키로 끌어다 놓고, **API 토큰**에 토큰을 붙여 넣은 뒤 **연결 / 다시 불러오기**를 클릭합니다.
3. 오버레이(목록에서 검색과 ★ 즐겨찾기 가능)와 키의 동작을 고릅니다. 양식의 편집 내용은 바로 UNO로 갑니다. **UNO에 저장했습니다.**가 나올 때까지 기다리세요.
4. 모든 필드 옆에 **?**가 있습니다. 포인터를 올리거나 Tab으로 이동하면 그 필드가 하는 일을 읽을 수 있습니다. Esc로 닫습니다.

## 언어

플러그인은 포르투갈어(브라질), 영어, 스페인어, 이탈리아어, 독일어, 일본어, 중국어(간체), 한국어, 프랑스어를 지원합니다. **자동 (OpenDeck 언어)**을 고르면 OpenDeck 설정에서 선택한 언어를 따릅니다. 설정 페이지에서 고른 언어가 우선합니다. OpenDeck에는 이탈리아어가 없으므로 이탈리아어는 설정 페이지에서만 고를 수 있습니다. OpenDeck의 언어를 바꾼 뒤에는 플러그인이 읽을 수 있도록 인스펙터나 설정 페이지를 다시 여세요.

## 트리거

트리거는 vMix의 트리거처럼 이벤트가 일어나면 기능을 실행합니다. 최대 30 000 ms의 지연 뒤에 오버레이를 표시하거나 숨깁니다. 이벤트: OBS 장면이 프로그램에 들어가거나 나감, 스트리밍 시작 또는 종료, 녹화 시작 또는 종료, UNO 오버레이가 방송에 나가거나 내려감(버전 1.0의 "이 오버레이가 방송에 나갈 때 / 내려갈 때" 연결). **트리거 추가**로 필요한 만큼 추가하세요. 각 트리거는 지우지 않고 끌 수 있습니다.

모든 트리거는 플러그인 로그에 받은 이벤트, 판단(실행했는지 무시했는지와 그 이유), UNO에서의 결과를 토큰 없이 기록합니다.

## 배타 그룹

같은 그룹의 오버레이는 동시에 방송되지 않습니다. 하나를 표시하면 키가 화면에 없는 것까지 포함해 나머지가 숨겨집니다. 오버레이 키는 이름으로 그룹을 고르고, 시간과 구성원은 설정 페이지에서 정합니다.

# 동작 방식 {#how-it-works}

- **전역 대기열.** 모든 장치의 키, 노브, 인스펙터가 하나의 대기열에 들어갑니다. UNO 작업은 한 번에 하나씩 순서대로 실행됩니다. 같은 필드를 여러 번 돌리면 한 번의 기록으로 합쳐집니다.
- **제한.** UNO가 알려 준 제한에 도달하면 대기열은 다음 시간 창까지 기다립니다. uno 무료 요금제는 App API 호출이 하루 10 000회로 제한되며, 상태 키가 횟수를 셉니다.
- **기록.** 기록은 서버가 확인해야만 완료됩니다. 시간 초과 뒤에 저절로 다시 시도하지 않습니다.
- **방송 중 편집.** 오버레이가 방송 중이면 변경이 없는 시간(기본 1000 ms)이 지난 뒤에야 편집을 보냅니다. 시청자는 반쯤 입력된 단어를 보지 않습니다. 인스펙터를 닫거나, 다른 필드로 옮기거나, 키를 누르거나, 패닉을 누르면 즉시 보냅니다.
- **화면에 없는 키.** Auto Close 타이머와 이미 누른 동작은 프로필을 바꿔도 계속됩니다. 키 설정이 실제로 바뀌거나, 패닉을 누르거나, 다시 누를 때만 취소됩니다.

# 제한 사항 {#limitations}

- **뷰어와 노브.** 뷰어 키와 그 노브는 둘 다 화면에 있을 때만 동작합니다. 노브가 고르고 있는 내용을 보관하고, OpenDeck은 선택된 프로필의 노브만 플러그인에 알려 주기 때문입니다.
- **복원.** 복원이 다시 표시할 오버레이 묶음은 메모리에만 있습니다. 플러그인을 다시 시작하면 사라집니다.
- **트리거 지연.** 이미 세고 있는 트리거 지연은 트리거를 편집해도 계속됩니다. 패닉으로 취소할 수 있습니다.
- **삭제한 키.** OpenDeck은 키를 삭제할 때와 프로필을 바꿀 때 같은 이벤트를 보내므로, 세고 있던 Auto Close는 정상적으로 끝납니다(최대 120초).
- **마이그레이션.** 버전 1.0의 트리거는 해당 키가 적어도 한 번 나타날 때만 전역 목록으로 옮겨집니다.
- **퀴즈.** 정답 공개는 범용 동작입니다. 오버레이가 정답을 공개하는 데 쓰는 필드와 값을 고르세요.

# 사용 예 {#use-cases}

## 스코어보드

팀마다 숫자 필드 키(키에 +1, +2, +3… 표시), 점수마다 값 표시 키, 되돌리기, 잠금, 팀이 진영을 바꿀 때 진영 교체, 피리어드용 순환, 마지막에 2초 동안 누르는 초기화.

## 퀴즈

캐러셀을 켠 슬롯 휠 노브: 한 칸 돌릴 때마다 다음 문제가 방송되고, 누르면 오버레이를 표시하거나 숨깁니다. 정답 공개 키가 정답을 공개하고 맞는 보기를 강조 필드에 복사합니다. 다음 문제로 넘어가면 다시 자동으로 숨겨집니다.

## 시계

텍스트 필드에 쓰는 시계 키: 카운트다운, 카운트업, 현재 시각, 종료 시각까지를 마무리 색상과 함께 표시합니다. 노브에서는 돌려서 시간을 조정하고 뷰어 키가 보여 줍니다.

## 티커와 목록

입력한 목록, .txt 또는 .csv 파일을 쓰는 데이터 소스를 오버레이의 필드에 연결하고, Auto Next와 반복을 사용할 수 있습니다.

## OBS Studio

OBS 장면 키는 프로그램 장면을 바꾸고 오버레이를 표시할 수도 있습니다. 트리거를 쓰면 "Webcam" 장면이 프로그램에 들어갈 때 카메라 자막을 표시하고 나갈 때 숨길 수 있습니다. OBS 브라우저 새로 고침은 여러 브라우저 소스, 또는 한 장면의 모든 브라우저 소스를 다시 불러옵니다.

# 문제 해결 {#troubleshooting}

- **"출력 URL이 아니라 제어용 API 토큰을 입력하세요."** 토큰(문자, 숫자, `_`, `-`)만 붙여 넣으세요.
- **"UNO HTTP 4xx".** 토큰이 틀렸거나 취소되었습니다. **API Description**에서 다시 복사하세요.
- **"UNO HTTP 429".** 요청이 너무 많습니다. 잠시 기다리고, 같은 토큰으로 UNO를 조회하는 도구는 피하세요.
- **"OBS에 연결되지 않았습니다…".** 설정 페이지에서 설정하고 OBS가 열려 있는지 확인하세요.
- **톱니바퀴를 눌러도 아무것도 열리지 않음.** 기본 웹 브라우저가 설정되어 있지 않습니다. `xdg-settings get default-web-browser`로 시스템이 쓰는 브라우저를 확인하세요.
- **키가 경고만 표시함.** 데스크가 잠겨 있거나(데스크 잠금이 빨간색) 키가 허용된 OBS 장면 밖에 있습니다.
- **트리거가 실행되지 않음.** 플러그인 로그를 보세요. 각 트리거가 실행되었는지 무시되었는지와 그 이유를 기록합니다. 로그: `~/.local/share/opendeck/logs/plugins/dev.br.consciencia.opendeck.uno-overlays.sdPlugin.log`

# 개인정보와 보안 {#privacy}

오버레이의 이름과 텍스트는 개인 데이터이며 UNO로 전송됩니다. 플러그인은 작성자에게 아무것도 보내지 않으며 로그에 토큰을 기록하지 않습니다. 토큰은 이 컴퓨터의 OpenDeck 설정에 보관되며, 설정 페이지는 토큰이나 OBS 비밀번호를 다시 보여 주지 않습니다. 저장된 장면과 로그는 요청에 따라 삭제할 수 있습니다(저장된 장면 삭제, 로그 지우기). 브라질 LGPD에 따른 권리를 행사하려면 프로젝트에 issue를 등록하세요. 자세한 내용은 플러그인의 PRIVACY.md와 SECURITY.md를 참고하세요.
