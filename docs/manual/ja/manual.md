# はじめに {#introduction}

UNO Overlays は、Linux の OpenDeck から [UNO](https://overlays.uno)（Singular.live）のオーバーレイをキーとノブで操作するプラグインです。表示と非表示、サーバーのスロット、スコアボード、時計、データソース、投票、目標、マクロ、OBS Studio、診断に対応します。

Rise Mode Vision 01（15 キー）と Vision Sound 01（6 キー、3 つのノブ、画面のない 3 つのボタン）向けに設計されていますが、OpenDeck が対応するすべてのデバイスで動作します。

- すべてのキーが状態を表示します。アイコンはオフエア中は**白**、オンエア中は**明るい赤**です。状態は UNO からリアルタイムに届きます。
- すべての UNO 操作は、どのデバイス、キー、ノブ、インスペクターからでも、**1 つのグローバルキュー**を通り、1 つずつ順番に実行されます。
- トリガー、排他グループ、コントロールアプリの一覧は**グローバル**です。画面にどのプロファイルやデバイスが表示されていても動作します。

# インストール {#installation}

## 必要なもの

- Linux 版 OpenDeck 2.6.0 以降。
- HTTPS 証明書付きの Python 3.10 以降（Debian/Ubuntu: `sudo apt install python3 ca-certificates`）。
- UNO と通信するためのインターネット接続。
- OBS Studio 28 以降（OBS のアクションとトリガーを使う場合のみ）。
- ほかには何も要りません。唯一の依存ライブラリ（`websockets`）はパッケージに含まれています。

## インストールと更新

1. リリースから `opendeck-uno-overlays-<バージョン>-linux.plugin.zip` をダウンロードします。
2. OpenDeck で **Plugins → Install from file** を開き、ファイルを選びます。
3. インストールすると以前のプラグインフォルダーが置き換えられます。キー、ノブ、設定はそのまま残ります。プラグインとアクションの識別子は変わっていません。
4. キーが更新されない場合は、OpenDeck を再起動してください。

![OpenDeck: Plugins → Install from file](botao_instalar_plugins.jpg)

## バージョン 1.0 からの更新

- オーバーレイキーのトリガーは、各キーが最初に表示されたときに自動でグローバル一覧へ移ります。一度も表示されないキー（別のプロファイル、接続されていないデバイス）は、一度表示されるまで古いトリガーを保持します。更新後に、そのプロファイルを一度開いてください。
- オプション「オンエア中の編集（任意）– 隠して変更し、再表示」はなくなりました。オンエア中の編集は、設定ページで決めた待ち時間の後、常に直接書き込まれます。

# 最初の手順 {#first-steps}

1. UNO でオーバーレイのコントロールアプリを開き、**? → API Description** でトークンをコピーします。アドレスの `/controlapps/` と `/api` の間の部分です。OBS で使う出力 URL ではなく、コントロール用のトークンを使ってください。
2. OpenDeck で **UNO Overlays** のアクションをキーにドラッグし、**API トークン**にトークンを貼り付けて **接続 / 再読み込み** をクリックします。
3. オーバーレイ（一覧には検索と ★ お気に入りがあります）と、キーの動作を選びます。フォームの編集はそのまま UNO に送られます。**UNO に保存しました。** と表示されるまで待ってください。
4. すべてのフィールドの横に **?** があります。ポインターを重ねるか Tab で移動すると、そのフィールドの説明が表示されます。Esc で閉じます。

## 言語

プラグインはポルトガル語（ブラジル）、英語、スペイン語、イタリア語、ドイツ語、日本語、中国語（簡体字）、韓国語、フランス語に対応しています。**自動（OpenDeck の言語）**では OpenDeck の設定で選んだ言語に従います。設定ページで選んだ言語が優先されます。OpenDeck にはイタリア語がないため、イタリア語は設定ページでのみ選べます。OpenDeck の言語を変えたときは、プラグインが読み直せるようにインスペクターか設定ページを開き直してください。

## トリガー

トリガーは、vMix のトリガーと同じように、イベントが起きたときに機能を実行します。最大 30 000 ms の遅延の後にオーバーレイを表示または非表示にします。イベント: OBS のシーンがプログラムに入る・出る、配信の開始・終了、録画の開始・終了、UNO のオーバーレイがオンエアになる・オフエアになる（バージョン 1.0 の「このオーバーレイがオンエア／オフエアになったとき」の連携）。**トリガーを追加** で必要なだけ作成できます。どのトリガーも削除せずにオフにできます。

各トリガーはプラグインのログに、受け取ったイベント、判断（実行したか無視したか、その理由）、UNO での結果を、トークンなしで書き込みます。

## 排他グループ

同じグループのオーバーレイが同時にオンエアになることはありません。1 つを表示すると、キーが画面にないものも含めて他が隠れます。オーバーレイキーはグループを名前で選び、時間とメンバーは設定ページで決めます。

# 仕組み {#how-it-works}

- **グローバルキュー。** すべてのデバイスのキー、ノブ、インスペクターが 1 つのキューに入ります。UNO の操作は 1 つずつ順番に行われます。同じフィールドへの回転は 1 回の書き込みにまとめられます。
- **制限。** UNO が知らせる制限に達すると、キューは次の時間枠まで待ちます。uno の無料プランでは App API の呼び出しが 1 日 10 000 回までで、ステータスキーが回数を数えます。
- **書き込み。** 書き込みはサーバーが確認したときだけ確定します。タイムアウト後に自動で繰り返すことはありません。
- **オンエア中の編集。** オーバーレイがオンエア中は、変更のない間（既定 1000 ms）が空いてから編集を送ります。視聴者が書きかけの言葉を見ることはありません。インスペクターを閉じる、別のフィールドに移る、キーを押す、パニックを押すと、すぐに送られます。
- **画面にないキー。** Auto Close のタイマーとすでに押した操作は、プロファイルを切り替えても続きます。キーの設定が実際に変わったとき、パニック、または新たに押したときだけ取り消されます。

# 制限事項 {#limitations}

- **バイザーとノブ。** バイザーキーとそのノブは、両方が画面にあるときだけ動作します。ノブが選択中の内容を保持し、OpenDeck は選択中のプロファイルのノブしかプラグインに知らせないためです。
- **復元。** 復元で戻すオーバーレイの組はメモリにだけあり、プラグインを再起動すると失われます。
- **トリガーの遅延。** すでにカウント中のトリガー遅延は、トリガーを編集しても続きます。パニックで取り消せます。
- **削除したキー。** OpenDeck はキーを削除したときもプロファイルを切り替えたときも同じイベントを送るため、カウント中の Auto Close は通常どおり終わります（最大 120 秒）。
- **移行。** バージョン 1.0 のトリガーは、そのキーが少なくとも一度表示されたときだけグローバル一覧に移ります。
- **クイズ。** 答えを表示は汎用のアクションです。オーバーレイが答えの表示に使うフィールドと値を選んでください。

# 使用例 {#use-cases}

## スコアボード

チームごとの数値フィールドキー（キーに +1、+2、+3… と表示）、スコアごとの値の表示キー、元に戻す、ロック、チームがサイドを替えるときのサイドチェンジ、ピリオド用のサイクル、最後に 2 秒長押しするリセット。

## クイズ

カルーセルをオンにしたスロットホイールのノブ: 回すたびに次の問題がオンエアになり、押すとオーバーレイを表示または非表示にします。答えを表示キーが答えを表示し、正解の選択肢を強調用フィールドにコピーします。次の問題になると自動で再び隠れます。

## 時計

テキストフィールドに表示する時計キー: カウントダウン、カウントアップ、現在時刻、終了時刻までのカウントに、終了間際の色を付けられます。ノブでは回して時間を調整し、バイザーキーで表示します。

## ティッカーとリスト

入力したリスト、.txt または .csv ファイルを使うデータソースを、オーバーレイのフィールドに割り当てます。Auto Next とループに対応します。

## OBS Studio

OBS シーンキーはプログラムのシーンを切り替え、オーバーレイを表示することもできます。トリガーを使えば、シーン「Webcam」がプログラムに入るとカメラのテロップを表示し、出ると隠せます。OBS ブラウザ更新は、複数のブラウザソース、またはシーン内のすべてのブラウザソースを再読み込みします。

# トラブルシューティング {#troubleshooting}

- **「出力 URL ではなく、コントロール API トークンを入力してください。」** トークン（英字、数字、`_`、`-`）だけを貼り付けてください。
- **「UNO HTTP 4xx」。** トークンが誤っているか無効にされています。**API Description** でもう一度コピーしてください。
- **「UNO HTTP 429」。** リクエストが多すぎます。少し待ってください。同じトークンで UNO に問い合わせるツールは避けてください。
- **「OBS に接続していません…」。** 設定ページで設定し、OBS が開いているか確認してください。
- **歯車を押しても何も開かない。** 既定のブラウザーが設定されていません。`xdg-settings get default-web-browser` でシステムが使うブラウザーを確認できます。
- **キーが警告しか表示しない。** デスクがロックされている（デスクロックが赤）か、キーが許可された OBS シーンの外にあります。
- **トリガーが実行されなかった。** プラグインのログを見てください。各トリガーが実行されたか無視されたか、その理由を書き込みます。ログ: `~/.local/share/opendeck/logs/plugins/dev.br.consciencia.opendeck.uno-overlays.sdPlugin.log`

# プライバシーとセキュリティ {#privacy}

オーバーレイの名前とテキストは個人データであり、UNO に送られます。プラグインは作者に何も送らず、ログにトークンを書きません。トークンはこのコンピューターの OpenDeck の設定に保存され、設定ページがトークンや OBS のパスワードを表示し直すことはありません。保存したシーンとログは、求めに応じて削除できます（保存したシーンを削除、ログを消去）。ブラジルの LGPD に基づく権利を行使するには、プロジェクトに issue を作成してください。詳しくはプラグインの PRIVACY.md と SECURITY.md を参照してください。
