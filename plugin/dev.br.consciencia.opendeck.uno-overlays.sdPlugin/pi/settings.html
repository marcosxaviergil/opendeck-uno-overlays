UNO Overlays settings

Language

OBS Studio (obs-websocket 5), used by every key

In OBS: Tools → WebSocket Server Settings. Enable the server, then copy the port and the password.

Edits while on air
Control apps

Keys register a control app when its token connects. Triggers, groups, Status and Panic use this list, also for keys that are not on screen.

Triggers

They run whatever profile or device is on screen. Each one: when the event happens, show or hide an overlay after the delay.

Exclusive groups

Showing an overlay of a group hides the others of the same group. Overlay keys choose their group; time and members are here.
